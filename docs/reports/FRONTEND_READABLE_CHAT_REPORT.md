## Что изменено

- Сообщения ассистента: небольшой DOM-Markdown subset — абзацы/переносы, strong/em, простые списки, inline/fenced code. Нет innerHTML, eval, CDN/шрифтов/библиотек. HTML/script/SVG/event-attrs — буквальный текст; Markdown-images не создают img и не вызывают загрузок. Ссылки только разобранные http/https без credentials/control/пробелов/backslash, открываются новым окном с noopener noreferrer; прочие схемы/относительные ссылки остаются текстом. User-текст, имена файлов, ошибки и tool JSON не интерпретируются как Markdown. Это subset, не полная CommonMark-совместимость; неподдержанное остаётся текстом.
- Карточки: русские названия/краткие итоги по фактическим полям. Слой before→after/value, импорт/число объектов/ID/габариты, машина/режим/backend, метаданные, профиль/материал, статусы нарезки/экспорта и оценки STE. Массив настроек сокращён до первого небольшого набора в основном потоке; полный ответ/ограничения остаются в деталях. Нет придуманных before, отсутствующих единиц/оценок или подтверждения незнакомой формы; неизвестный ok=true — нейтральная карточка. Неизвестные ключи словарей не наследуют constructor/__proto__. Backend.matches_mode=false явно показывает несовпадение режима/движка нейтральным состоянием.
- JSON и технические IDs/коды доступны в закрытых нативных details→summary «Технические детали» с текстовым pre. Нет отдельного диагностического UI или изменения событий. Состояния определяются словами, а не только цветом. Исторический finished без started не выдумывает raw-null/доказанный отказ; marked pre-validation явно отклонён до запуска. Неизвестное исполнение/timeout/stale/failed/observation stopped отличаются, кнопок автоматического повтора нет.
- Сетевой timeout: основной текст коротко сообщает об отсутствии ответа, отсутствии отмены прежних tools и необходимости проверить результаты/UI без повтора. **Полный исходный текст с номером обращения/complete-временем/бюджетом/подтверждёнными вызовами сохранён в закрытых деталях**, не потерян и не приписан времени генерации провайдера. Из timeout не делается вывод «ничего не изменено».
- Sidebar: главные статус/известный процент либо «Прогресс не сообщён», stale/ошибка и время/длина/масса с единицами. ID/подробное observation — в details. При stopped виден warning «Обновление не удалось: операция могла продолжиться», не выдаётся остановка engine. Idle LLM отдельно от состояния операций. Время — форматирование полученных секунд; собственных оценок/формул расхода нет, null не превращается в0. Подтверждённый0 остаётся0. Числа не округляются, десятичный разделитель русский; известные mm/°C/mm/s подписаны мм/°С/мм/с, неизвестные единицы сохраняются. cylindrical обозначен «5D Spiral (цилиндрический)».
- Вложения/скачивание: прежние picker/upload/pending/client_message_id/lease/backend не менялись. Файлы имеют читаемые имя/вид/размер, прежний строгий относительный download URL; повтор/stale/refresh/410 не дублируют карточки и убирают ссылку при известной неактуальности. Публичные metadata артефакта доступны в закрытых деталях.
- CSS/HTML: viewport, min-width0/flex ограничения, перенос длинных имён/слов, локальный scroll кода/JSON, читаемые отступы и focus-visible для keyboard. На узком экране sidebar и чат располагаются вертикально; существующий бренд/структура сохранены. Дополнительных endpoint/зависимостей/сборки нет.
