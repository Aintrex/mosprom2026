# ТЗ 01: реальные проверки локального плагина

Дата: 23.10.2026. Адрес, предоставленный пользователем: `http://127.0.0.1:50998/`. Это адрес текущего запуска, не постоянный порт для кода.

**Решение ведущего: ТЗ 01 принято.** Сценарий выполнен в STE Slicer **7.10.12**, машина **Stereotech Hybrid 530 V5.2.4**, режим **3D**. Приёмка касается только объёма ТЗ 01; LLM, режимы 5D, модели, слайсинг и экспорт не проверялись.

## Выполнено

- Установленные `AIAssistant.py`, `agent/mcp.py`, `agent/service.py`, `agent/tools.py`, `slicer/adapter.py`, `slicer/qt_bridge.py` в `%APPDATA%/steslicer/7.10/plugins/AIAssistant/` побайтово совпадают с текущими исходниками по SHA-256.
- Реальный `GET /api/health`: HTTP 200, `status=ok`, `mode=scaffold`.
- Реальный `POST /mcp`, `tools/list`: HTTP 200; доступны `assistant_status`, `get_setting`, `set_setting`.
- Реальный `tools/call get_setting`, аргументы `{"key":"layer_height","scope":"global"}`: HTTP 200, `isError=false`, результат `{"ok":true,"data":{"key":"layer_height","scope":"global","value":0.1,"unit":"mm"}}`.

- [Исходное значение на скриншоте пользователя](evidence/task01/layer-height-before.png): верхнее поле Layer Height = 0.1 мм. Профиль и режим на этом фрагменте не видны.
- После повторного чтения 0.1 выполнен реальный set_setting на 0.12: `before=0.1`, `after=0.12`, `ok=true`. Отдельный get_setting подтвердил 0.12 мм. Печать и слайсинг не запускались.
- [Скриншот после изменения](evidence/task01/layer-height-changed.png) подтвердил Layer Height = 0.12 мм в UI; видимые зависимые Classic Layer Height и 5D Surface Layer Height также стали 0.12 мм.
- Восстановлено исходное значение: set_setting вернул `before=0.12`, `after=0.1`, `ok=true`. Отдельное чтение подтвердило 0.1 мм.
- Реальные некорректные запросы `value=-1` и `scope=extruder` отклонены с JSON-RPC `error.code=-32602`. Итоговый get_setting после обоих запросов вернул прежние 0.1 мм.
- [Скриншот машины и восстановленного значения](evidence/task01/machine-and-restored-value.png) подтвердил выбранную машину **Stereotech Hybrid 530 V5.2.4** и Layer Height = **0.1 мм** в UI. Также видны материал PLA, профиль качества Fine, активный Main Extruder и отсутствие загруженной модели. Значение printing_mode и версия GUI на этом скриншоте не отображаются.

Это подтверждает доступность HTTP/MCP, чтение, запись, изменение UI и отклонение неверных аргументов в данном запуске на требуемом профиле машины. Значения не являются константами для других профилей и запусков. **Исходные 0.1 мм восстановлены и подтверждены API и UI.** Результаты сохранены локально в игнорируемом `tmp/task01_runtime_state.json`.
