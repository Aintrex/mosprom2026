## Результат

- Создан `docs/CURRENT_VERSION_ACCEPTANCE.md` (175 строк): последовательность для публикации **84c1e021f3bfc94c3d8ddc72a041091f2e2dc3de**, различие исходников/целой установленной копии, новый текущий порт, чтение машины и backend, каталог120 с адресными keys/category/query/двумя небольшими страницами и пустым поиском.
- Подготовлен один выбранный float setter global либо подтверждённого extruder: before/метаданные → одна запись → readback/UI → отдельное явное восстановление. При ошибке/unknown только чтение и остановка, без finally-отката/повтора. Учтены отсутствие extruder_id даже null для global, обязательная строка для extruder, ограничения API и сохранение override/stale slice.
- Даны два учебных факта Альфа/PETG и Бета/PLA: отдельные чаты → saved → выбор → обычный restart → проверка отдельного контекста, expired-вложение/старые ID, удалениеB с подтверждением → повторный restart. Теоретические/читающие/изменяющие промпты разделены. Таблица исходов остаётся незаполненным протоколом пользователя, успехов заранее нет.
- Существующая большая native-приёмка профилей/сцены/трёх режимов/engine/writers/Preview/reopen дана ссылками, без дублирования сценария. Старые baseline296/инструкции явно отделены от текущей публикации.
- По разрешению ведущего исправлен `plugin/README.md`: get_slicer_state не перечисляет extruders; пользователь задаёт известную позицию по проверенной конфигурации, readonly describe подтверждает/отвергает её до записи. `"0"` — пример, не угадываемая позиция из несуществующего поля.
- Точечно уточнены два старых RAM-параграфа `docs/API_CONTRACT.md`: plugin2G имеет локальный архив, dev без архива — RAM; лимиты текущего процесса/диска и процессная идемпотентность различаются. Остальной контракт не переписывался.
