# Ревью читаемого интерфейса чата

24.10.2026. Исходники приняты после просмотра app.js/style.css/index.html, семантических JS-проверок и FRONTEND_READABLE_CHAT_REPORT.md. Backend, REST, CSP, транспорт, Qt, native tools и локальная timeout-диагностика в рамках frontend-этапа не менялись.

## Результат

Ассистентские сообщения отображают безопасный небольшой набор Markdown через DOM: абзацы, strong/em, списки, inline/fenced code. User-текст, имена файлов, ошибки и JSON остаются буквальными. HTML/script/SVG и Markdown-images не создают исполняемых/внешних узлов; ссылки ограничены http(s) без credentials. Это subset, не полный CommonMark.

Основной поток показывает фактические русские итоги инструментов/единицы вместо JSON. Неизвестная форма ответа не становится успешным изменением. Сохранены before/after, отказ до запуска, неизвестный native-исход, failed/stale, неподтверждённый прогресс и отсутствие результата. Мismatch backend/mode виден явно. Исходные JSON и диагностика доступны в закрытых details без клиентского retry.

По визуальному замечанию ведущего сокращены сетевые ошибки и боковые статусы. Raw числовая диагностика не удалена: полный исходный текст находится в закрытых деталях. На виду остаются понятная причина/следующий шаг и существенные предупреждения, включая observation stopped (операция могла продолжиться), stale и неопределённый результат. Поля nullable не подменяются нулём, полученные числа не округляются.
