## UI

- Вложения: имя, формат, размер, миниатюра фото (blob URL, освобождается; CSP дополнен только `img-src 'self' blob:`), фазы «загружается / готово / ошибка», «прикреплено к сообщению» и «импортировано в сцену» (по подтверждённому `load_model_file`). Формат и размер проверяются до загрузки по лимитам из `/api/status`; файл с ошибкой блокирует отправку и убирается кнопкой. Повтора загрузки нет.
- Панель «Модели на сцене»: живой `list_models`/`get_model_state` через `/mcp`, выбор объекта, поворот X/Y/Z, перемещение в мировые мм (Y вверх), масштаб, удаление с подтверждением. Поля парсятся в JSON-числа; пустое, единицы, NaN/Infinity не отправляются. Ошибка backend показывается красной карточкой с причиной; успех — с позицией до/после и предупреждениями. Исчезнувший ID сбрасывается. Причины недоступности: агент работает, нарезка/экспорт, загрузка, переключение, пустая сцена.
- Enter отправляет сообщение, Shift+Enter — перенос; быстрый запрос «Подготовить модель к печати».
- Ширина 360 px проверена в браузере без горизонтального скролла (dev-сервер, ответы `/mcp` подменены в окне просмотра).
