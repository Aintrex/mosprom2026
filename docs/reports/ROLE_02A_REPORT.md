# Роль 2A — upload файлов

Реализовано по `docs/tasks/ROLE_02A_UPLOAD.md` в существующем `plugin/AIAssistant`. Передано на ревью; 2B не начато. До работы проверен git status; существующие изменения ТЗ 08/09, черновик 10, документы ведущего и временные Word-файлы сохранены. Git-фиксаций, установки и обращений к провайдеру/принтеру не было.

## Результат

- `uploads.py`: stdlib-хранилище с непрозрачными ID и серверными физическими именами; один экземпляр на AgentService. Конструктор не обращается к диску. Метаданные публикуются после завершённой записи и проверки; неизвестный ID не превращается в путь.
- `server.py`: POST `/api/files`, один multipart file → 201 `{file_id,name,kind,size_bytes,mime_type}`. Ответ не содержит локального пути. Остальные маршруты, JSON64KiB, loopback, Host/Origin собственного порта, CSP и static whitelist сохранены. GET/download/публичного metadata endpoint нет.
- Модели STL/OBJ/3MF до50MiB, JPG/JPEG/PNG до5MiB, обёртка64KiB, сохранённые файлы до250MiB на процесс. Потоковое чтение блоками до64KiB, один upload одновременно (409 busy), обязательный Content-Length, без chunked. Неверные тип/структура/размер — 400/415/413; закрытие — 503. Ошибки не раскрывают содержимое/пути.
- Проверяется содержимое, а не MIME клиента: PNG chunks/CRC, JPEG markers, ASCII/binary STL, OBJ с геометрическими записями. 3MF: ZIP/CRC и обязательные XML-части, без извлечения; до1024 частей, раскрытый объём200MiB, обязательная XML-часть16MiB. Опасные/дублирующиеся имена, encryption, symlink, DTD/entities отклоняются.
- Реестр и квота защищены от параллельной записи; недописанные/непрошедшие проверку файлы не регистрируются. Коллизия физического имени не перезаписывает и не удаляет существующий файл; коллизия file_id не заменяет запись. Очистка касается только созданных хранилищем файлов.
- `AgentService.close()` прекращает операции и запускает cleanup вне Qt. Очистка ждёт upload/leases, удаляет только учтённые файлы и свой пустой каталог. Чужой файл внутри не удаляется. Dev-сервер при выходе ограниченно ждёт cleanup вне Qt.

Для 2B оставлен внутренний API: `metadata(file_id)` — копия; `model_path(file_id)` — lease доверенного модельного пути; `read_image(file_id)` — MIME/байты; `close()`. Повторный параллельный lease.close атомарен. Файловые методы вызываются вне Qt. Lease потребуется держать до фактического конца reader, включая timeout/shutdown; подключение к ModelRegistry здесь не выполнялось. Один только ModelRegistry.finish/_release ещё не доказывает завершение reader.

## Ручной запрос и границы

Запустить `python scripts/dev_server.py`, взять напечатанный порт и выполнить из другого PowerShell:

```powershell
$uploadPort = [int](Read-Host 'Порт dev-сервера')
$uploadPath = Read-Host 'Абсолютный путь тестового файла'
$uploadForm = 'file=@"{0}"' -f $uploadPath.Replace('\', '/')
curl.exe --include --max-time 30 --form $uploadForm "http://127.0.0.1:$uploadPort/api/files"
```

Для этого примера используйте имя без кавычек. Ожидается201 и метаданные без пути. Браузерный пример FormData и точные ограничения — `docs/API_CONTRACT.md`; готовность frontend уточнена в `docs/FRONTEND_INTEGRATION.md`. Ручной curl в установленном STE здесь не выполнялся; автоматические HTTP-проверки идут через настоящий локальный сервер без Qt.

Upload ещё не прикрепляет файл к сообщению, не импортирует модель в STE и не передаёт картинку LLM. `attachment_ids=[]`, capabilities.attachments/downloads=false и отсутствие file picker сохранены. Геометрическая корректность требует штатного reader; проверки JPEG/PNG не декодируют изображение полностью. Некоторые нестандартные варианты OBJ/STL/3MF вне документированных границ будут отклонены. Хранилище не восстанавливает ID после перезапуска; при аварийном завершении/ошибке ОС возможны временные остатки, чужие каталоги не сканируются. TTL/скачивание не добавлены.

Установленный плагин не обновлялся. Реальные модели/GUI/Preferences/provider не проверялись; ручная приёмка ТЗ 03/04 и остальных native-сценариев остаётся открыта.

Во время2A `slicer/`, схемы инструментов и LLM-цикл не менялись. После этого отчёта работа остановлена для ревью;2B назначается отдельно.
