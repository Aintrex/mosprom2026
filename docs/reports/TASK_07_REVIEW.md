# Ревью ведущего: ТЗ 07

23.10.2026. Проверены settings.py, его подключение в adapter.py и ToolRegistry, 13 новых сценариев и сохранение прежних проверок. Исполнитель завершил API-контракт, README, PLAN и ручной сценарий; ведущий просмотрел эти изменения перед фиксацией основы.

## Результат

Блокирующих замечаний в рассмотренной логике нет. Сохранены прежние layer_height/global и общий lock; настройки читаются/пишутся через существующий QtBridge. Целевой экструдер выбирается из global_stack.extruders по строковой позиции, активный в UI не подставляется.

Типы всех 19 ключей независимо сопоставлены с выданным fdmprinter.def.json: совпадают. Семантика hasProperty/getProperty проверена по DefinitionContainer/ContainerStack, settable_globally и settable_per_extruder — по регистрации свойств в SteSlicerApplication. Изменение userChanges подтверждается чтением результата и идентичности стеков; неуспешный или неопределённый setter инвалидирует нарезку. No-op не делает лишнюю запись.

Числа конечны, bool отделён от числа; int не округляется; enum выбирается по runtime options. Жёсткие границы запрещают запись, warning bounds добавляют предупреждение. Missing/disabled/readonly/неподтверждённые метаданные не заменяются собственным успешным ответом.

## Независимая проверка

Полный набор на bundled Python 3.13.6, 23.10.2026:

```text
python -m unittest discover -s tests
Ran 153 tests in 9.473s
OK
```

Первый запуск в restricted sandbox не прошёл из-за WinError 5 для временных каталогов и WinError 10013 для loopback-сокетов. Повтор с разрешённым доступом прошёл без изменения кода. Это ограничение среды проверки; в успешном прогоне используются подмены API, а не настоящий STE.

Набор проверяет прежний контракт, валидацию до API, два экструдера без смены UI-позиции, runtime options/bounds, неопределённый setter, смену стека, busy, timeout, shutdown и актуальность нарезки. В него включены грамматика Python 3.5 и api:5.

## Открытые ограничения

Native-приёмка расширенных настроек ещё не выполнена. Требуются сравнение UI/целевого и другого экструдера, восстановление исходных значений и подтверждение поведения зависимых параметров. Установленный плагин не обновлялся. ТЗ 03–06 также сохраняют свои открытые runtime-проверки. Это ревью разрешает сохранить программную основу, но не объявляет завершённым полный продукт хакатона.
