## Основа и слияние

Ветка создана именно от актуального `origin/main` **2aea9b5da4fd11a750074d76766935abc57ba175**. В неё слита `origin/main1.0` **9efda60** с остановкой перед commit для проверки. Текстовых конфликтов нет. Настоящие main/origin/main не изменялись. Отдельная `codex/fix-setting-version` (87ef1bc) этим слиянием не включается: пользователь попросил основу реального main и main1.0.

В main1.0 добавлены UI вложений и управления моделями, прямой MCP через учёт записей сервиса, ожидание завершения собственных slice/export, увеличенные бюджеты, уменьшение повторной передачи фото. Это исходные изменения участника, а не доказательство работы в STE. Подтверждённая ранее строгая числовая нормализация сохранена; участник дополнительно ввёл LLM-only преобразование bool/пагинации и global extruder_id:null. Прямой MCP остаётся строгим. Наличие строки в пользовательском вызове подтверждено, но объяснение её появления union-схемой в отчёте участника не доказано.

При интеграционном ревью дополнительно исправлено:

- Запрос чата больше не принимается, пока выполняется прямая ручная запись через MCP. Раньше блокировка работала только в обратном направлении. Status отражает такую занятость. Тест проверяет параллельный вызов, ноль запросов LLM до освобождения и возможность продолжить после него.
- Некорректный key-массив/объект не вызывает TypeError в предварительной обработке bool; остаётся для штатной валидации.
- Сетевой обрыв ручного преобразования не называется «Отклонено до запуска». UI показывает неизвестный результат, предлагает чтение сцены и не повторяет запись. Только доказанная ошибка JSON-RPC до исполнения получает прежнюю надпись.

## Копирование и ZIP

Точный текст ошибки копирования пользователь пока не предоставил, поэтому её причина не объявляется устранённой. В исходниках не обнаружены ссылки/нестандартные Git-типы файлов плагина, которые объясняли бы невозможность переноса. Проверка PowerShell Copy-Item в новый временный каталог внутри workspace успешна: **87 файлов, все SHA256 совпали**. AppData и установленная копия не затрагивались.

Добавлен простой `scripts/package_plugin.py`: чистый ZIP с `AIAssistant/` и `INSTALL.txt`, без скрытых файлов, кэша Python, конфигурации пользователя и всего репозитория. Не перезаписывает существующий архив, не устанавливает плагин, отклоняет неполный источник/ссылки. Готовая локальная копия — ignored `tmp/packages/AIAssistant-main1-integration.zip`: **31 исходный файл**, целостность и совпадение с текущим checkout проверены. Тест распаковывает ZIP в временную plugins-папку и сравнивает содержимое, проверяет отсутствие двойной вложенности и приватных/кэш-файлов. Инструкция: `docs/PLUGIN_COPY_AND_ZIP.md`.
