## Изменения

- `web/index.html`, `web/style.css`: слева одна кнопка «Новый диалог», прокручиваемые диалоги с датами и быстрые команды снизу. Сцена, нарезка/экспорт и подключение перенесены в верхние раскрытия. На телефоне список диалогов сворачивается; Escape возвращает фокус к кнопке. Контролы сцены сохранены.
- `web/app.js`: один свёрнутый журнал фактических действий на `turn_id`, шаги адресуются парой `turn_id/tool_call_id`. Повторные события обновляют шаг, поздний started не затирает finished. Без идентификаторов связи не придумываются: события показываются отдельными блоками с явной пометкой.
- В сводке отдельно считаются подтверждённые шаги, ошибки, выполняющиеся/ожидающие операции, stale и неизвестный исход. Отказ validation/executed=false, timeout и начатое неподтверждённое преобразование различаются. Ошибки и неизвестный исход остаются отдельными видимыми сообщениями вне закрытого журнала. Started без результата при завершённом ходе не объявляется успехом.
- В шагах сохранены before/after, единицы и точные значения настроек; JSON, схемы и служебные ID находятся в закрытых технических деталях. Заметка о разборе аргументов одна на журнал; подробности остаются у соответствующего шага.
- Composer использует три независимые колонки. Textarea растёт от 40 до 160 px с дополнительным ограничением высотой окна, затем прокручивается внутри. После принятой отправки размер сбрасывается. Enter/Shift+Enter, IME/isComposing/keyCode229 и прежнее тело явного повтора сохранены.
- Выбранные файлы оформлены карточками: формат/миниатюра, имя, размер, состояние и удаление. При ошибке есть заметное предупреждение над списком, даже если ошибочная строка ниже его видимой части. Вложения в истории находятся внутри сообщения пользователя. Upload и успешный импорт в сцену различаются; историческое вложение помечается недоступным.
- G-code/3MF перенесены из composer в отдельное сообщение ленты. Обновление по artifact_id сохраняет одну карточку; stale удаляет ссылку. Заголовок «Файлы готовы» появляется только при наличии разрешённого актуального скачивания; иначе доступность обозначена неподтверждённой. Размеры форматируются для чтения.
- При чтении старой переписки новые события не прокручивают её вниз. Кнопка перехода к новым событиям находится внутри области ленты и не перекрывает выросший ввод.
