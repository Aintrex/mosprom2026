## Независимые проверки

- Повторён полный `python -m unittest discover -s tests -v`: **72 теста, OK**, 5.205 секунды, bundled Python 3.13.6. Разрешены временные loopback-соединения тестов, реальный STE Slicer не изменялся.
- `git diff --check` — без замечаний.
- Все обращения к контейнерам, менеджерам, Preferences и узлам находятся внутри Qt-операций; worker только ждёт и координирует подтверждение.
- Позиция экструдера, root ID и resolved container ID разделены. Выбор не зависит от активного в UI экструдера и отображаемого названия.
- Профиль подтверждается по quality_type и ID глобального/экструдерных контейнеров, материал — по root/resolved ID конкретной позиции. Возврата setter недостаточно для успеха.
- Снимки overrides проверяются после записи; качество выбирается публичным setter с no_dialog=True. Потенциальный discard/диалог при смене материала блокируется до setter, Preferences не меняются.
- Custom-профили защищены явным ограничением, no-op не вызывает лишний setter; материал возвращает фактическое качество после штатного перерасчёта.
- Режим, качество и материал используют общую блокировку; сохранены ошибки/таймауты, отсутствие автоматического повтора и отмена просроченных pending-callback.
- Базовая высота профиля не подменяется текущим override; неизвестная вычисляемая высота возвращается null. Dev-режим не имитирует успех.
