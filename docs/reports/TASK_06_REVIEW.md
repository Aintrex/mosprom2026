## Независимые проверки

- Полный unittest: **140 тестов, OK, 10,130 секунды**, bundled Python 3.13.6. Сохранены предыдущие 121 сценарий. Грамматика Python 3.5, JSON-примеры и git diff --check прошли.
- Handler выбран по типу: mesh GCodeWriter для траектории, workspace 3MFWriter для проекта. Собственные генераторы не используются.
- WriteFileJob стартует из Qt, native writer вызывается через штатный worker. Декорированные write/snapshot не вызываются синхронно внутри Qt bridge. Наш I/O worker не добавляет чтений app; внутренние обращения native writer — граница встроенного API.
- Актуальность slice_id и guard переиспользованы из 05. Stale/unknown slice, concurrent UI writer и отсутствие writer не выдаются за успех.
- Успех требует собственного finished, результата без ошибки, flush/close, проверки файла и повторного подтверждения контекста. Проверяются CRC/XML/workspace 3MF и присутствие исходного engine G-code. Выходной файл создаётся эксклюзивно; неполный файл не регистрируется как артефакт.
- Timeout не закрывает stream продолжающегося job. Проверены позднее завершение, shutdown, partial publication и сохранность существующего пользовательского файла.

## Границы и продолжение

Подмены не подтверждают наличие writers/Savitar и фактические сигналы/формат файлов установленной сборки. Проверка ZIP/XML не заменяет повторное открытие 3MF с проверкой настроек/геометрии, а проверка G-code — штатный Preview. Ограничения на root-модели и отсутствие служебных потомков явные, геометрия не упрощается скрыто.

Штатный декоратор может зависнуть при исключении внутри Qt callback; это timeout/неопределённость с удержанием ресурса, без успешной заглушки и без патча дистрибутива. Ручная приёмка ТЗ 03–06 остаётся открытой.
