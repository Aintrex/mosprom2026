# Очистка личных данных перед публикацией

24.10.2026. По прямому поручению пользователя проверены текущие отслеживаемые и новые файлы, включая XML и свойства Word/PowerPoint. В runtime плагина персональные пути не обнаружены; менять его поведение ради очистки не потребовалось.

Из инструкций, отчётов и примеров удалены персональные пути профиля Windows, личная почта, явные ссылки на аккаунт владельца и локальные ID чатов. Вместо них используются `<REPO_ROOT>`, `<SOURCE_ROOT>`, `%APPDATA%`, путь/URL от пользователя и нейтральное обозначение автора. Команды изменены так, чтобы принимать свой путь/URL; собственные значения не предлагается угадывать. Тестовые фиктивные credentials из сценариев защиты и сведения об источниках заимствованного кода не удалялись.

Открытые Word-оригиналы не закрывались и не перезаписывались. Их очищенные варианты опубликованы под именами CHECKPOINT_01_SCRIPT_PUBLIC.docx, PROGRESS_SIMPLE_PUBLIC.docx и TEST_AI_ASSISTANT_WINDOWS_PUBLIC.docx; исходные открытые файлы оставлены локально и явно игнорируются Git. INSTALL_PLUGIN_WINDOWS.docx очищен на месте. Удалены персональные creator/lastModifiedBy там, где они были; связанные ссылки в Markdown обновлены. Замена закрытых оригиналов не требовалась для остальных документов.

Четыре очищенных документа экспортированы через Word/Poppler:4/7/2/8 страниц.11 изменившихся страниц просмотрены;10 остальных PNG побайтово совпали с прежними рендерами. Переполнения/обрезки на просмотренных страницах не обнаружено. LibreOffice отсутствует, поэтому стандартный renderer недоступен.79 PowerShell-блоков связанных инструкций разобраны Parser без ошибок и без выполнения команд. Повторные Python/JS/runtime-тесты для этой очистки документации не запускались.

Очистка относится к текущим публикуемым файлам. Старые коммиты, Git author/committer, удалённые копии и уже скачанные документы автоматически не очищаются. История не переписывалась, force push не выполнялся. Это ограниченная проверка известных персональных строк и форматов credentials, а не гарантия отсутствия любых неизвестных секретов. Установка, AppData, реальная LLM/ключи, STE и принтер не использовались.
