# Проверка и сдача

## Каркас

- [ ] Плагин виден в меню выданного STE Slicer после перезапуска.
- [ ] Окно браузера открывает локальный адрес; повторное открытие использует тот же сервер.
- [ ] В чате явно обозначено, что ответ демонстрационный.
- [ ] Ошибка сервера отображается пользователю.
- [ ] Выход из слайсера закрывает сервер.

## Приёмка полного решения

- [ ] URL/model/key вводятся в настройках; ключ не попадает в исходники, браузер и логи.
- [ ] LLM действительно вызывает инструменты и получает результаты/ошибки.
- [ ] MCP initialize, tools/list и tools/call проверены отдельно от UI.
- [ ] Все настройки, сцена и backend обслуживаются в Qt-потоке.
- [ ] Проверены глобальные и экструдерные настройки, профили и материалы.
- [ ] Проверены classic, cylindrical и cylindrical_full на Stereotech Hybrid 530 V5.2.4.
- [ ] Загрузка STL/OBJ/3MF и JPG/PNG работает; фото передаются в LLM корректно.
- [ ] Изменения ориентации/позиции/масштаба и авторасстановка видны в слайсере.
- [ ] Прогресс, время и расход материала берутся из слайсера.
- [ ] Ошибка слайсинга не превращается в сообщение об успехе.
- [ ] Сохранённые 3MF повторно открываются с настройками, режимом, материалом и ориентацией.
- [ ] G-code непустой, соответствует выбранной модели и режиму, проверен в предпросмотре.
- [ ] Проверена новая установка плагина по README на другой машине/конфигурации.
