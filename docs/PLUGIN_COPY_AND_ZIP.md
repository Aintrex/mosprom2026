# Как перенести плагин из этой ветки

Копировать нужно **только `plugin/AIAssistant`**, а не весь репозиторий, каталог `plugin` или папку `.git`.

1. В STE Slicer откройте **Справка → Показать папку конфигурации**. Оставьте эту папку открытой.
2. Сохраните проект и полностью закройте STE Slicer.
3. Если скачивали ZIP из GitHub, сначала нажмите **Извлечь всё**. Откройте распакованную папку репозитория, затем `plugin`. Там должна быть папка `AIAssistant`.
4. Старый `plugins/AIAssistant` сохраните как резервную копию **вне `plugins`**. Затем замените целиком только этот плагин. Другие настройки и плагины не трогайте.
5. Проверьте итог: `plugins/AIAssistant/plugin.json`. Вложенной папки `AIAssistant/AIAssistant` быть не должно.
6. Запустите STE Slicer, выберите **AI Assistant → Open chat**. Копирование не переносит ключ LLM: его вводят в настройках приложения.

Для установки не нужен каталог Program Files. Путь к пользовательской конфигурации берите из самого приложения; он может отличаться между сборками.

Если Windows сообщает «Отказано в доступе» или «Файл используется», сохраните точный текст ошибки. Проверьте, что STE закрыт, ZIP распакован и выбрана пользовательская конфигурация. Не удаляйте всю конфигурацию и не меняйте права системы наугад. Если копирование прошло, но меню отсутствует, это уже отдельная ошибка загрузки плагина: нужен лог старта STE, предварительно убрав ключи и личные данные.

## Чистый ZIP для передачи

Разработчик с Python может собрать архив из корня репозитория:

```powershell
python scripts/package_plugin.py --output tmp/packages/AIAssistant-main1-integration.zip
```

Выберите новое имя, если архив уже существует: упаковщик не перезаписывает файлы. В ZIP только `AIAssistant/` и `INSTALL.txt`; исключены `.git`, скрытые файлы, `.env`, `__pycache__` и `.pyc`. Архив не содержит настроек LLM, диалогов или файлов из пользовательской конфигурации. Скрипт ничего не устанавливает и STE не запускает. ZIP лежит в игнорируемом `tmp/`, в Git добавляется скрипт, а не локальный архив.

В этой интеграции копирование исходной папки через PowerShell в временный каталог прошло; SHA256 всех87 файлов совпал. Чистый ZIP содержит31 исходный файл и инструкцию; его распаковка проверена с побайтовым сравнением. Это не проверка прав доступа в AppData на другой машине и не подтверждение запуска в STE. Точный сбой копирования пользователя пока не воспроизведён.
