# Результаты для жюри

Для каждой выданной модели создайте отдельный каталог:

```text
results/<model_name>/
  project.3mf
  result.gcode
  chat_01.png
```

Здесь пока нет результатов. Они должны быть получены через работающий чатбот, затем проверены в STE Slicer. Не создавайте пустые файлы вместо артефактов.

3MF и G-code внутри этого каталога разрешены `.gitignore`. Перед staging проверьте объём; сдача всё равно производится ZIP-архивом по инструкции организаторов.
