# AI Assistant для STE Slicer (3D / 5D)

Плагин интеллектуального ИИ-технолога и MCP-сервера (JSON-RPC 2.0) для **STE Slicer (Stereotech, форк Cura 3.6, API v5)**.
Полностью совместим с **Python 3.5+** (написан на стандартной библиотеке Python без внешних зависимостей и `f-строк`).

## 1. Архитектура и возможности

- **Единое окно «Модель → Настройка → Слайсинг → G-code / 3MF»**:
  - Веб-интерфейс чат-бота (SPA на чистом HTML + CSS + JS) открывается в браузере на `http://127.0.0.1:<port>/`.
  - Принимает текстовое описание задачи, ТЗ, фото деталей (`JPG/PNG` в `base64 image_url`) и 3D-модели (`STL/OBJ/3MF`).
  - Отображает все вызванные агентом **MCP-инструменты (`tools/call`)** с их аргументами и результатами.
- **Собственный MCP-сервер (JSON-RPC 2.0 поверх HTTP `/mcp`)**:
  - Реализует `initialize`, `notifications/initialized`, `tools/list`, `tools/call`, `ping`.
  - Включает **16 инструментов**: управление глобальными настройками и настройками экструдера, выбор режима печати (`classic` 3D, `cylindrical` 5D Spiral, `cylindrical_full` 5D), выбор и создание профилей и материалов, загрузка и трансформация моделей в сцене, встроенный геометрический анализатор STL (расчёт габаритов, объёма, площади нависаний $>45^\circ$ и симметрии вращения), запуск слайсинга и экспорт `.3mf` и `.gcode`.
- **Двухрежимная работа (Windows STE Slicer + автономный симулятор на macOS)**:
  - **Внутри STE Slicer (Windows)**: обращается к `SteSlicerApplication.getInstance()` и потокобезопасно изменяет сцену и настройки в главном потоке Qt через `app.callLater(...)`.
  - **На macOS / без слайсера**: запускает локальный симулятор `Stereotech Hybrid 530 V5.2.4`, реально парсит бинарные и текстовые `.stl` из папки `Примеры деталей` и генерирует валидные `project.3mf` и `result.gcode`.

## 2. Установка в STE Slicer (Windows)

1. Скопируйте папку `AIAssistant` в папку плагинов пользователя STE Slicer:
   `%APPDATA%\steslicer\7.x\plugins\AIAssistant`
   *(В меню слайсера: **Справка → Показать папку конфигурации → plugins**).*
2. Перезапустите STE Slicer.
3. Откройте меню **Расширения → AI Assistant → Open chat**.
4. В открывшемся окне браузера нажмите **«⚙ Настройки LLM»** и введите выданные организаторами параметры:
   - **Base URL**: `https://api.timeweb.ai/v1`
   - **Модель**: `dashscope/qwen3.8-flash`
   - **API Key**: введите ключ организаторов (сохраняется в настройках приложения, не хардкодится в исходниках).

## 3. Запуск и проверка на macOS

Откройте терминал в папке `AIAssistant` и выполните:

```bash
python3 AIAssistant.py 8765
```

Откройте `http://127.0.0.1:8765/` в браузере. Слева доступны кнопки быстрого запуска всех **7 тестовых кейсов хакатона**.

## 4. Автоматическая сборка всех 7 кейсов для сдачи (`generate_submission.py`)

Чтобы автоматически прогнать все 7 деталей из папки `Примеры деталей` через MCP-инструменты и собрать готовый архив `submission_team.zip` (со структурой `plugin/` и `results/<model_name>/project.3mf` + `result.gcode`):

```bash
python3 generate_submission.py
```
